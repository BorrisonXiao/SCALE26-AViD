From a claim to a verdict: the pipeline

How AViD turns one claim and a video-with-audio into a per-part, per-channel verdict: parse the claim, rewrite it into checkable units, build a semantic factor tree, drop the units that aren't independently checkable, probe each surviving unit with a multimodal model, and reconcile everything with a tree-CRF. This note is the current end-to-end picture, plus an ablation of the check-worthiness gate.

End to end

Seven stages

Everything upstream of the CRF exists to turn a raw claim into a tree of units that each have a real audio-visual truth value. Figure 1 is the whole path; the stages after the parse are the ones this note is about.

The middle of the pipeline

Turning the parse into checkable units

Raw parse tokens are the wrong things to verify. Parse normalization rewrites them — cheap deterministic rules first, semantic-role labelling next, a language model only on the residue — into a tree whose units each have an audio-visual truth value. Three unit-quality fixes landed recently; each is id-preserving (only the unit's surface or role changes), so annotations already collected stay aligned:

ProblemBeforeAfter
Light/motion verb + particleevent probed as “getting?”“getting out?” (particle folded into the verb; the argument “the tram” stays its own unit)
Manner adverbialbare “hand” probed (“Is a hand visible?”)bare “hand” → na; the phrase “by hand” is verified by the manner factor
Abstract / relational noun“position” probed (“Is a position visible?”)“position” → na (no independent audio-visual referent)

Table 1. The three unit fixes, shown on the running claim “The tram driver gets out of the tram to change the switch to the correct position by hand.” The particle fix is deterministic; the manner and abstract-noun drops are the check-worthiness gate (below).

The gate

Dropping units that aren't independently checkable

A unit earns a probe only if it has a standalone audio-visual referent — something a viewer could point to, read as on-screen text, or hear. Abstract or relational nouns (“position”, “conditions”, “role”), bare manner adverbials (“by hand” → “hand”), pronouns, and metaphors do not; concrete objects, people, places, vehicles, and named on-screen sources do. Deterministic rules catch the clear cases with high precision; a language model judges the residue in context — the same “resolve-once, rules-then-LLM” shape as the rest of normalization. The distinction is genuinely context-dependent, which is why a flat rule over-fires (it would drop concrete instruments like “school buses” alongside “hand”) and the model earns its place.

Ablation

Local (Qwen) vs. external (codex) check-worthiness gate

We ran the gate two ways over the same 166 candidate units with the same prompt: a local model (Qwen3-30B via vLLM, on the cluster) and an external API model (codex / gpt-5.6-sol). The point is to check whether the reproducible, no-external-API local model is a sound substitute — and it is.

OutcomeUnitsExamples
Both models abstain (drop)46position, conditions, role, amounts, sight, recovery operation, vote share
Both models keep (probe)94tram, switch, crowd, moon, robots, police officers
codex-only abstain (Qwen keeps)13court, tariffs, calculus, negotiations, injunction, approval
Qwen-only abstain (codex keeps)13earthquake, winds, lane, night, region, two-thirds, timestamps

Table 2. Check-worthiness gate, local Qwen vs. external codex, on 166 candidate entity units (each abstains 59). Agreement is 140/166 (84%). The 26 disagreements are the inherently subjective middle — policy/abstract nouns codex leans to drop, quantities/times codex leans to keep.

Read, and the decision

84% cross-model agreement means the gate is robust where it matters; the 16% disagreement is exactly the fuzzy set a human annotator should adjudicate rather than trust either model on. Because the local and external models are effectively interchangeable on the clear cases, we use the local Qwen gate for all current and future experiments — it is reproducible, needs no external API, and keeps claim text on the cluster (the frozen-local-model principle the project verifies elsewhere). codex remains only a cross-model sanity check.

Result

What the annotator sees

On the current gold surface (43 claims), the pipeline yields 439 probeable units and 68 na units. Each probeable unit carries a read-only reference prediction from the multimodal model (re-probed against the final units); na units carry none. The human annotation controls always start blank and are stored separately, so the model reference can never leak into the gold labels.
