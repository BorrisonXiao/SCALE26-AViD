Tree-CRF verifier The model Overlapping evidence

Design note · open question · 12 August 2026

What does an interior node's probe measure?

In the current model the probe at an interior node scores the whole subtree — the full proposition hanging under that node — not the node on its own. That is a modelling choice with a real cost: the same pixels get counted more than once. This note works through whether it is the right thing to do, why you cannot simply fall back to probing the head word, and what a clean fix looks like.

The question

The interior emission is really a subtree probe

The method note defines the emission \(\varphi_v\) as "the multimodal model's own probe of node \(v\)." For a leaf like a cart that is honest — the probe asks "is a cart visible?" But for an interior event node the probe asks about the entire span hanging under it — "is a man pushing a cart?" — which is the whole proposition, not the node alone. So the object the CRF calls a node emission is actually a subtree emission. Is that the right thing to do, or should each node carry its own local probe, combined somehow with the subtree probe?

Short answer

The concern is correct and it is already on the record — the project's own CRF-semantics review names the model "a parse-indexed tree CRF over overlapping proposition units" and flags the double-counting as unresolved. But the fix is neither "probe the head word instead" nor "multiply a node probe by a subtree probe." Both mishandle overlapping evidence. The clean move is to make the probes cover disjoint pieces of the claim, one per logical conjunct.

The current behaviour

What each node actually probes today

Each CRF variable scores support for the text that was queried against the clip — and for events and the root that text is the full proposition, which literally contains its descendants' text. Take the claim "Huge crowd standing together chanting":

The same holds up a chain of nested events (a matrix verb and its purpose clause), so the overlap compounds toward the root. Figure 1 shows the pattern.

Why it matters

Overlapping probes double-count evidence

The method note justifies multiplying the emissions by appealing to conditional independence — "local emissions give exactly the independence a CRF assumes." That justification is false at interior event nodes, because their observation is not local: it re-reads the same frames as the children. When the clip clearly shows everything, the model multiplies

\[ P(\text{man visible}) \times P(\text{cart visible}) \times P(\text{man pushing cart}), \]

but the last term is high because the man and the cart are visible. Agreement inflates confidence super-linearly, and when the terms disagree the trade-off has no principled scale — you are multiplying correlated probabilities with no weight to discount the redundancy. The asymmetric necessity edge softens this (a child mostly vetoes a supported parent rather than boosting it), which is why the raw verdict is empirically robust to unit changes. But the double-count still distorts exactly the quantities that are the project's contribution: the per-node marginals, the existence-versus-binding split, and the per-part modality attribution — a "video / audio" label read off an event node currently describes its whole subtree, not the node.

The tempting non-fix

Why you cannot just probe the head word

The obvious reaction is "make the interior emission local — probe only the head, pushing." That throws away the two things the subtree probe was doing right:

  • Binding needs a composed probe. The head word alone cannot tell you the man is the one pushing. The dancing decoy — a woman dancing while a man watches, for "a man is dancing" — is caught only by a probe of the composed span, never by the parts. This is the whole reason interior nodes are probed at all.
  • The root needs claim coverage. The claim-level verdict is read off the root, so the root probe must cover the full claim; shrinking it to a head word breaks the readout (this is exactly why the surface was changed to full-subtree roots, taking claim coverage from 48% to 96%).

So "go local" is not the answer. The real problem is not that the probe is big — it is that the same evidence sits on two factors.

The clean resolution

One probe per conjunct

A proposition is a conjunction, and the single subtree probe collapses several conjuncts into one. Written out in the neo-Davidsonian style familiar from semantic role labelling,

\[ \exists e:\; \operatorname{push}(e)\;\wedge\;\operatorname{Agent}(e,\text{man})\;\wedge\;\operatorname{Theme}(e,\text{cart}). \]

Each conjunct is a different observation you can probe separately, so assign each to exactly one factor. Then no frame feeds two factors, binding is preserved (it lives in the relational factors), and inference stays exact — a factor tying an event to its arguments keeps the graph singly connected, so belief propagation is unchanged in form.

ConjunctProbeWhere it lives
the man exists · the cart exists"is a man visible?" · "is a cart visible?"local unary at each argument node
a pushing event occurs"is someone pushing something?"local-ish unary at the event node
the man is the agent · the cart is the theme"is the man the one pushing?" · "is the cart the thing pushed?"a binding factor between the event and each argument

Table 2. The single subtree probe ("is a man pushing a cart?") conflates all four rows. Splitting them removes the overlap by construction and — a bonus — lets you attribute the binding to a channel separately from the arguments (e.g. the man and cart are on video, but the relation is asserted only in the narration).

Formally this is the identity the model should factor along:

\[ P(\text{proposition}) \;=\; P(\text{parts exist}) \;\times\; P(\text{binding}\mid\text{parts exist}). \]

Existence goes on the argument unaries; the binding-given-existence residual goes on the relational factor. This is also the principled reading of the nearest competitor, BTProp: treat each node's probe as a noisy observation of that node's own latent truth, with the tree carrying the logical relations — so the observations are of distinct truths, not re-readings of one another. The practical catch is eliciting the residual: it means getting the model to presuppose the arguments ("a man and a cart are present — is he pushing it?"), which multimodal models honour unreliably. That risk is what motivates the fallback below.

Answering the literal question

On "combining" a node probe with the subtree probe

Combining is right only in the conditional sense above, never as a product of two overlapping marginals. Putting a local head emission and a full-proposition emission on the same node and multiplying gives

\[ \underbrace{P(\text{head alone})}_{\text{node probe}}\;\times\;\underbrace{P(\text{whole proposition})}_{\text{subtree probe}}, \]

and since the proposition already entails the head, this counts the head evidence twice — it makes the double-counting worse, not better. "Combine" is correct when the second term is the residual \(P(\text{binding}\mid\text{parts})\), wrong when it is another overlapping whole.

If clean probes are unreliable

A cheaper fallback: learn the weights

Keep the proposition probes, but stop treating them as calibrated likelihoods to be multiplied, and read the model as a genuine discriminative CRF — which is its correct formal status anyway. Then

\[ \log P(z\mid x) \;=\; \sum_v w_v \,\log \varphi_v(z_v) \;+\; \sum_{(p,c)} \log \psi(z_p, z_c), \]

and you fit a weight \(w_v\) per node role (or per depth of overlap) so the redundancy is discounted. CRFs are built to tolerate overlapping features — but only once the weights are learned; you cannot plug in raw probabilities and multiply. This is a handful of scalars, the same machinery already proposed for the edge strengths, and the gold surface needed to fit it is being built regardless. The cost is that it spends the "training-free" property, which is why the choice is a genuine fork.

The tension in one line

Pick two of three

You can have at most two of: (a) plug in the model's probabilities untrained; (b) keep proposition-level probes at interior nodes; (c) read calibrated per-node marginals as the interpretable output.

  • The current model quietly wants all three — the double-count is that contradiction surfacing.
  • One probe per conjunct (the fix above) keeps (a) and (c), gives up (b): interior emissions become conjunct-local.
  • Learn the weights keeps (b) and (c), gives up (a).

Because the decomposition — property (c) — is the contribution, the conjunct-split is the recommended direction, with learned weights as the fallback if the relational probe cannot be elicited cleanly.

Two easy confusions

What this is not

  • Not the same as deliberate redundancy. Probing the same binding two ways (a dependency node and a constituency node) is averaging repeated reads of one quantity — that reduces variance and is fine. Nested parent-contains-child multiplication introduces bias (over-concentration), not just variance. Different phenomenon.
  • Orthogonal to the state-space fix. The separate proposal to use explicit support / refuted / can't-tell states (and make "can't-tell" structurally neutral) fixes a different bug — an evidence-free node scoring two-thirds support. Do both; they don't interact.

Resolving it empirically

How to decide it

The binding-decoy perturbation split is exactly where the existence-versus-binding separation bites, so it is the discriminating test. On that split — and, once available, on the gold decomposition — compare three variants: (i) the current proposition-everywhere model; (ii) conjunct-local unaries plus a relational binding factor; (iii) proposition probes with fitted per-role weights. Report per-node label correctness and faithfulness (does the verdict move when a node label is dropped or corrupted), not just the root verdict — the verdict is already known to be insensitive, so it cannot adjudicate this.

Status

This note records the original open question. The follow-up conjunct-local semantic factor-tree proposal now specifies and implements the recommended annotation pilot; final adoption for the paper still depends on the experiment above.
