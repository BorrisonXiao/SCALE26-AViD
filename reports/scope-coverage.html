1. Keep an event in the context the sentence gives it

Scope means whether an event is independently asserted, depicted, planned, investigated or discussed. The existing logical form already supports nested propositions. The fix changes attachment before predicates are emitted; it does not change how DeepProbLog multiplies or sums probabilities.

Table 2. The three reviewed scope errors and their repairs. Links show the actual saved predicates and structures.
Original exampleEarlier errorCurrent structure
Video depicts Blue Ghost preparing for landingLanding also appears outside depiction and preparation.Video depicts → preparation → goal: landing on the moon.
Investigation into Shi Yongxin violating religious preceptsViolation is a relative description of the person.Investigation → investigated content: violation; the reported conclusion stays attributed to the results.
Dialogue of why they are thereThe presence clause becomes a separate world assertion.Dialogue → question content: why they are there; no reason or pronoun referent is invented.

How the code decides: it uses the governing word, preposition and dependency path. For prepare for, an existing nominal event moves into a purpose proposition; without an event frame, the goal stays a noun phrase and no actor is invented. For investigation into, a subject-plus-gerund construction moves under the investigation. For a question under dialogue/discussion/question, the WH word follows that noun’s dependency path and stays inside question content.

The lexical entries are deliberately limited. Ordinary prepare dinner remains an argument, and ordinary relatives are not all reinterpreted as allegations. Nested negation and existing source routes remain attached to their event. This is a bounded repair, not a general solution to every embedded clause.

2. Retain content, then make remaining omissions explicit

A small dolly creaks while a man uses it to move large stacks of chairs. previously lost the dolly, its size and its sound. The parser called creaks a plural noun. The repair requires an adjacent singular nominal, a verb-lexicon match and a finite temporal clause; it then restores the grammatical subject and uses the existing frame builder. The sound and use are linked by while; movement remains a purpose. It is still unresolved, with that requirement visible in the output.

Connected proper-name spans repair Bering Straight and four Sagaing Fault cases. An identifier property retains 76 in news 76 and 120 in one highway-sign example. An existing complete name must never be shortened. A number already retained in Apollo 11 gains no redundant constraint. Original spellings are preserved.

The audit compares source nouns, names, predicates, modifiers and numbers with the values reachable in the final logical form. It allows ordinary inflection and existing numeric operators such as at least. Schema keys, warnings, unused entities and graph IDs cannot hide an omission. Failed cases keep a diagnostic candidate but are refused by the strict entry point with a list of missing tokens.

Lexical coverage does not check all functional words, role assignments or internal relationships. It can pass a clause hidden inside an opaque string, and it may flag a legitimate paraphrase outside its normalization rules. It must not be reported as a semantic accuracy score.

Evaluation and limits

228 regression checks pass. These include all earlier checks, real-case requirements, complete-name and quantity controls, input immutability, and actual native DeepProbLog supported/refuted/unknown tests. The native goal test supplies an absent world landing while varying the scoped goal evidence: verification follows the goal evidence, without requiring an actual world landing. These are constructed evidence checks, not media measurements or training results.

The compiler was frozen before examining a newly reserved 20-case review. The compiler-author assistant saved intended readings before output inspection. Sampling excludes 150 recorded review sources; all corpus texts had been parsed previously. These are assistant judgments on a nonuniform fresh review sample, not human gold or corpus accuracy.
