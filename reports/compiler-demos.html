The quotation rules use both source spans and a uniquely bound artifact; they do not treat all quotation marks as inscriptions. Main-clause would is preserved literally. Embedded ambiguous would still refuses. Explicit generic comparative and universal constructions are flagged rather than given invented quantifier semantics. These checks do not cover every generic construction.

Complement classes use the official PropBank frames: look.02 expresses seeming, blame.01 has a blamed-content role, call.03 expresses demand, tweet.02 is a written message and sound.02 is noise production. Source constructions license the call/tweet/sound sense corrections; frame numbers are not global aliases. Names and explicit person-role nouns now outrank unrelated common-person tokens when adding grammatical number, so “people” does not make Trump or the narrator plural.

Paper evaluation and training policy

Every automatic test claim remains in the denominator. Report parsing coverage, fidelity on checked readings, verification performance and cost separately. Controlled relation training can use checked logical forms and generated binding edits with inspected text/media labels; this does not establish unrestricted end-to-end performance. The complete automatic test includes parsing failures. No empirical relation training is run here, and these results do not establish training readiness.
